# Модель даних проєкту "Dark Kitchen Plus"

База даних **dark_kitchen_plus** побудована на реляційному принципі та забезпечує зберігання інформації про користувачів, рецепти та всі необхідні сутності для управління кухнею.

---

## 1. Основні сутності та їх опис

### Таблиця Users (Користувачі)
Зберігає інформацію про всіх зареєстрованих користувачів системи.

| Поле | Тип даних | Обмеження | Опис |
| :--- | :--- | :--- | :--- |
| **user_id** | INT | PRIMARY KEY, AUTO_INCREMENT | Унікальний ідентифікатор користувача. |
| **username** | VARCHAR(50) | NOT NULL, UNIQUE | Унікальне ім'я користувача для відображення. |
| **email** | VARCHAR(100) | NOT NULL, UNIQUE | Електронна пошта, використовується для входу. |
| **password_hash** | VARCHAR(255) | NOT NULL | Хеш пароля (для безпечного зберігання). |
| **registration_date**| DATETIME | DEFAULT CURRENT_TIMESTAMP | Дата та час реєстрації. |

### Таблиця Recipes (Рецепти)
Зберігає основну інформацію про кожен рецепт.

| Поле | Тип даних | Обмеження | Опис |
| :--- | :--- | :--- | :--- |
| **recipe_id** | INT | PRIMARY KEY, AUTO_INCREMENT | Унікальний ідентифікатор рецепта. |
| **title** | VARCHAR(100) | NOT NULL | Назва рецепта. |
| **description** | TEXT | | Детальний опис рецепта. |
| **prep_time** | INT | NOT NULL | Час підготовки (у хвилинах). |
| **cook_time** | INT | NOT NULL | Час приготування (у хвилинах). |
| **servings** | INT | NOT NULL | Кількість порцій. |
| **user_id** | INT | FOREIGN KEY (Users) | Користувач, який додав рецепт (автор). |
| **category_id** | INT | FOREIGN KEY (Categories) | Категорія страви (наприклад, "Основна страва"). |
| **diet_id** | INT | FOREIGN KEY (Diets) | Дієта, до якої належить рецепт (наприклад, "Веганська"). |

---

## 2. Допоміжні та словникові таблиці

### Таблиця Categories (Категорії)
Словник для класифікації рецептів (наприклад, "Сніданок", "Десерт", "Салат").

| Поле | Тип даних | Обмеження | Опис |
| :--- | :--- | :--- | :--- |
| **category_id** | INT | PRIMARY KEY, AUTO_INCREMENT | Унікальний ідентифікатор категорії. |
| **name_ua** | VARCHAR(50) | NOT NULL | Назва категорії українською. |

### Таблиця Diets (Дієти)
Словник для позначення дієтичних обмежень (наприклад, "Вегетаріанська", "Без глютену").

| Поле | Тип даних | Обмеження | Опис |
| :--- | :--- | :--- | :--- |
| **diet_id** | INT | PRIMARY KEY, AUTO_INCREMENT | Унікальний ідентифікатор дієти. |
| **name_ua** | VARCHAR(50) | NOT NULL | Назва дієти українською. |

### Таблиця Ingredients (Інгредієнти)
Словник усіх можливих інгредієнтів.

| Поле | Тип даних | Обмеження | Опис |
| :--- | :--- | :--- | :--- |
| **ingredient_id** | INT | PRIMARY KEY, AUTO_INCREMENT | Унікальний ідентифікатор інгредієнта. |
| **name_ua** | VARCHAR(100) | NOT NULL | Назва інгредієнта українською. |

### Таблиця Steps (Кроки)
Послідовність кроків для приготування рецепта.

| Поле | Тип даних | Обмеження | Опис |
| :--- | :--- | :--- | :--- |
| **step_id** | INT | PRIMARY KEY, AUTO_INCREMENT | Унікальний ідентифікатор кроку. |
| **recipe_id** | INT | FOREIGN KEY (Recipes) | Рецепт, до якого належить крок. |
| **step_number** | INT | NOT NULL | Порядковий номер кроку (1, 2, 3...). |
| **description** | TEXT | NOT NULL | Опис дії для цього кроку. |

---

## 3. Зв'язуючі таблиці

### Таблиця Recipe_Ingredients (Інгредієнти Рецепта)
Зв'язує таблиці `Recipes` та `Ingredients` (багато-до-багатьох).

| Поле | Тип даних | Обмеження | Опис |
| :--- | :--- | :--- | :--- |
| **recipe_ingredient_id**| INT | PRIMARY KEY, AUTO_INCREMENT | Унікальний ідентифікатор зв'язку. |
| **recipe_id** | INT | FOREIGN KEY (Recipes) | Рецепт. |
| **ingredient_id** | INT | FOREIGN KEY (Ingredients) | Інгредієнт. |
| **quantity** | VARCHAR(50) | NOT NULL | Кількість (наприклад, "250 г", "2 шт.", "1/2 склянки"). |

---

## 4. Зв'язки між таблицями

* **Users** (1) **<->** **Recipes** (Багато): Один користувач може створити багато рецептів.
* **Categories** (1) **<->** **Recipes** (Багато): Одна категорія може містити багато рецептів.
* **Diets** (1) **<->** **Recipes** (Багато): Одна дієта може застосовуватися до багатьох рецептів.
* **Recipes** (1) **<->** **Steps** (Багато): Один рецепт має багато послідовних кроків.
* **Recipes** (Багато) **<->** **Ingredients** (Багато): Реалізовано через таблицю **Recipe_Ingredients**.
